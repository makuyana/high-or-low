# 🎮 Higher or Lower Game

A simple interactive desktop game built with **Python** and **CustomTkinter**, where players guess which celebrity has more Instagram followers.

## 📌 About the Project

Higher or Lower is a desktop guessing game inspired by the popular Higher or Lower game concept.

The game displays two celebrities. The first celebrity's follower count is visible, while the second celebrity's follower count is hidden.

Your job is to guess whether the second celebrity has **more or fewer followers** than the first.

Every correct guess increases your score, and the game continues with a new celebrity comparison. One incorrect guess ends the game.

## ✨ Features

- **Interactive GUI:** Built using CustomTkinter with a dark-themed interface.
- **Celebrity Comparisons:** Compare Instagram follower counts between celebrities.
- **Higher or Lower:** Choose whether the next celebrity has more or fewer followers.
- **Score Tracking:** Earn points for every correct guess.
- **Random Selection:** Celebrities are randomly selected from the game dataset.
- **Instant Feedback:** Receive visual feedback for correct and incorrect guesses.
- **Game Over:** The correct follower count is revealed when you make an incorrect guess.

## 🎯 How to Play

1. Launch the game.
2. Look at the first celebrity and their Instagram follower count.
3. Compare them with the second celebrity.
4. Click **Higher** if you think the second celebrity has more followers.
5. Click **Lower** if you think they have fewer followers.
6. Each correct answer increases your score.
7. One incorrect answer ends the game.
